## 🚀 Proyectos destacados

### 🚲 BikeShop: sistema de gestión para tienda de bicicletas
Aplicación full stack para inventario, proveedores, ventas y reportes.

- **Backend:** API REST con Spring Boot 3 y Java 21, autenticación **JWT** con roles (`ADMIN` / `TRABAJADOR`), reportes en **PDF y Excel**, documentación con Swagger y despliegue con **Docker Compose**.
- **Frontend:** Angular 16 + Angular Material, guards por rol, interceptor JWT, punto de venta con carrito y facturas.

[Backend](https://github.com/Rich4rdx/BikeShop-Backend) · [Frontend](https://github.com/Rich4rdx/BikeShop)

### 🤖 GastroSENA: agente de IA con MCP (proyecto en equipo)
Asistente que responde preguntas en lenguaje natural sobre el sistema de un restaurante. Un agente LLM consulta los microservicios Spring a través de un **servidor MCP**, expuesto con **FastAPI** (respuestas en streaming por SSE) y un bot de Telegram.

[Agente MCP](https://github.com/Brian7st/AgenteGastrosena-ServeMcp) · [Frontend Angular 20 + Nx + NgRx](https://github.com/Brian7st/GastrosenaFrontend) · [Inventario (Spring Boot)](https://github.com/Brian7st/Inventario-GastroSena)

### 🛒 Carrito de compras en JavaScript puro
Manipulación del DOM, persistencia con LocalStorage y pruebas. [Código](https://github.com/Rich4rdx/test-carrito) · [Demo](https://rich4rdx.github.io/test-carrito/)
